Linux, das mit deinem Kind mitwächst.

Eine Konfigurationsebene für Omarchy — kein Kinder-Tablet, ein echtes System.

GitHub Autor EN

Früher Entwicklungsstand · noch nicht einsatzbereit

omarchy-kids legt eine Konfigurationsebene über Omarchy — alterspassende Desktop-Profile, die mit deinem Kind mitwachsen, ein Kontrollzentrum für Eltern und sinnvolle Bildschirmzeit. Kein Fork, keine Kinder-App-Blase: Omarchy wird ganz normal installiert, omarchy-kids ergänzt Konfiguration, einen Hintergrund-Agenten und ein Kontrollzentrum obendrauf.

Alterstufen

Desktop-Profile, die mit dem Kind mitwachsen — vom ersten Klick bis zum eigenen Rechner.

Elternkontrolle

Ein Kontrollzentrum auf dem Elterngerät, das per SSH mit dem Kindgerät spricht.

Bildschirmzeit

Sinnvolle Limits statt starrer Sperren — auf einem echten, freien Linux-System.

omarchy-kids ist ein unabhängiges Projekt auf Basis von Omarchy — nicht offiziell mit Omarchy oder 37signals verbunden.
